# Fontrie (FontAtelier)
Make discovering and managing fonts more enjoyable and accessible.
**Fontrie** is a font management application for Windows 11.
It allows you to browse fonts installed on your computer, manage your own font files, preview fonts, and install or uninstall fonts.

## System Requirements
- OS: Windows 11
- Supported application language: Japanese
- Price: Free

**Note:** The application's user interface is currently available in Japanese only.

## Features
- Browse and search fonts
- Preview fonts
- Manage favorite and recently used fonts
- Organize fonts into groups
- Manage font sets
- View Windows fonts and installed fonts
- Install and uninstall fonts
- Customize display and preview settings
- View font license information

## Download
Download Fontrie from GitHub Releases.
Two installer formats are available:

### MSI Installer
An installer in Windows Installer format.
Recommended for users who prefer the standard Windows installation format.

### NSIS Installer
A setup installer.
When uninstalling Fontrie, you can choose whether to delete its user data.
Both installers provide the same application. Choose whichever format you prefer.

## Installation
1. Download either the MSI or NSIS installer from GitHub Releases.
2. Run the downloaded installer.
3. Follow the on-screen instructions.
4. Launch Fontrie after installation is complete.

## Uninstallation
Open Windows Settings, go to **Apps > Installed apps**, find Fontrie, and select Uninstall.
With the NSIS installer, you can choose whether to delete Fontrie's user data during uninstallation.

- If you choose to keep the data, your user data will be preserved.
- If you choose to delete the data, Fontrie's user data will be removed.

**Note:** Deleted user data, including settings and font management information, may not be recoverable. Back up any important data before uninstalling.
