# ふぉんとりえ（FontAtelier）
フォントとの出会いを、もっと楽しく、もっと身近に。
**ふぉんとりえ**は、Windows 11向けのフォント管理ソフトウェアです。
パソコンにインストールされているフォントや、自分で追加したフォントを一覧で確認し、プレビューや整理、インストール・アンインストールなどを行えます。

## 動作環境
- OS：Windows 11
- 対応言語：日本語
- 利用料金：無料

※現在、アプリ本体の表示・操作は日本語のみです。

## 主な機能
- フォントの一覧表示・検索
- フォントのプレビュー
- お気に入り・最近使用したフォントの管理
- フォントのグループ管理
- フォントセットの管理
- Windowsフォント・インストール済みフォントの確認
- フォントのインストール・アンインストール
- 表示方法やプレビュー設定のカスタマイズ
- ライセンス情報の確認

## ダウンロード
GitHub Releasesから、好みのインストーラーを選んでダウンロードしてください。
ふぉんとりえでは、次の2種類を配布しています。

### MSI版
Windows Installer形式のインストーラーです。
Windows標準のインストール形式を利用したい方におすすめです。

### NSIS版
セットアップ形式のインストーラーです。
アンインストール時に、ふぉんとりえのユーザーデータを削除するかどうか選択できます。
どちらを選んでも、ふぉんとりえを利用できます。お好きな方をお使いください。

## インストール方法
1. GitHub ReleasesからMSI版またはNSIS版をダウンロードします。
2. ダウンロードしたインストーラーを実行します。
3. 画面の案内に従ってインストールします。
4. インストール完了後、ふぉんとりえを起動してください。

## アンインストール方法
Windowsの「設定」から「アプリ」→「インストールされているアプリ」を開き、ふぉんとりえを選択してアンインストールしてください。

NSIS版では、アンインストール時にユーザーデータを削除するかどうか選択できます。
- 削除しない場合：ユーザーデータを保持します。
- 削除する場合　：ふぉんとりえのユーザーデータを削除します。

※ユーザーデータを削除すると、保存されている設定や管理情報などを復元できなくなる場合があります。必要に応じて事前にバックアップしてください。
